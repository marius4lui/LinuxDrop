# LinuxDrop 0.1.0-beta.1

First installable beta for **Ubuntu 24.04 amd64**. Includes the native GTK app,
background daemon, LocalSend and Quick Share engines, experimental AirDrop,
restricted radio helper, AWDL helper, GNOME extension and file-manager actions.
Quick Share and Nearby Share use the same backend.

## Install and send

Download `linuxdrop_0.1.0~beta.1_amd64.deb` and `SHA256SUMS` from the release.

```sh
sha256sum --ignore-missing -c SHA256SUMS
sudo apt install ./linuxdrop_0.1.0~beta.1_amd64.deb
```

Open LinuxDrop from the application menu. Drop files into Send, choose a device
and send. To receive, enable visibility and approve the incoming request.
Settings lets you choose the receive folder, protocols and preferred adapter.

For the optional desktop bubble, enable LinuxDrop in GNOME Extensions. Log out
and back in after the first installation if it is not listed. Click its top-panel
icon to open the bubble; it remains hidden until opened.

## AirDrop setup

1. Connect a dedicated idle Wi-Fi adapter that supports monitor mode and frame
   injection. Check the Hardware page for the detected adapter and backend status.
   An adapter used for the current Internet connection is protected.
2. Enable AirDrop in Settings. Authorize the restricted radio helper when asked.
   The application runs as your ordinary user.
3. On the Apple device, enable AirDrop reception for Everyone. Contacts-only
   authentication is not supported by this beta. Keep its AirDrop interface open
   while testing discovery.
4. To send, select the Apple device in LinuxDrop and confirm the request on it.
   To receive, make LinuxDrop visible, select it on the Apple device and approve
   the incoming request in LinuxDrop.
5. If discovery fails, inspect Hardware and backend status before sending again.
   A 2.4-GHz-only adapter has a limited AWDL channel choice; detected capabilities
   do not establish compatibility with a particular Apple device.

A VM needs a real suitable Wi-Fi adapter passed through to Linux for AWDL, and a
Bluetooth controller for BLE wake. Virtual Ethernet alone can run the UI and LAN
sharing, but cannot provide AirDrop radio transport. Bluetooth wake is optional;
opening the Apple sharing interface is the first practical discovery check.

## What was verified

- Release builds of the workspace and bundled AWDL helper on Ubuntu 24.04.
- Real TLS AirDrop send/receive with consent and byte-for-byte file verification.
- Previously installed native daemon/desktop and helper lifecycle checks against
  the same software revision; radio-driver boundaries were simulated.
- GNOME 46/50 native desktop acceptance, LocalSend HTTPS and Quick Share TCP
  protocol tests are recorded in `docs/acceptance` and `docs/PROGRESS.md`.

**Physical AirDrop interoperability with an iPhone/Mac and actual AWDL/BLE
hardware remains unverified.** LocalSend/Quick Share physical client acceptance
also remains pending. This is a beta, not a claim of universal device support.
The full implementation goal remains separate and unfinished.

Only the Ubuntu amd64 binary is published in this release. The matching source
archive contains locked dependencies, vendor patches and other distribution
build recipes. Existing older review packages are not release assets.
